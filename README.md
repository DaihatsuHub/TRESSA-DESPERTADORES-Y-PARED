# Tressa - Despertadores y Pared

Catálogo público responsive: 27 modelos (23 despertadores y 4 relojes de pared), 117 variantes de color.

- `products.json`: códigos internos, referencias del proveedor, medidas, funciones, colores y rutas de las fotografías.
- `assets/`: fotos originales por color, ambientaciones por modelo, logo e íconos del proveedor.
- `index.html`: catálogo, búsqueda, filtro por tipo de reloj y ampliación de imágenes.

Las referencias del proveedor se usan para relacionar los archivos y buscar; las tarjetas muestran el código interno TRESSA.

Publicación mediante GitHub Pages desde la rama `main`.
